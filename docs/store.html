Community Apps

The CydOs App Store

A directory of apps other people built for CydOs. Being honest about how this works: the CYD has no OTA or app-loading system, so nothing here installs itself - each entry is source you pull into your own build and reflash, same as the apps that ship in the box.

How "installing" an app actually works

Once your app is merged, it's not sitting in some marketplace waiting to be downloaded onto a running device - a GitHub Action automatically rebuilds the Community Edition firmware (every merged app baked into one image) and republishes it right here. Flashing that one file, with the same one-click installer as the main Flash page, is the "load it onto your CYD" step - no PlatformIO, no git, no code, on your end.

  1. 1
    Implement the App interface (onEnter/update/draw/onTouch - see App.h) in one self-contained header file.
  2. 2
    Fill out the form below and generate a submission - it packages your app's name/author/icon/description and code into a pre-filled GitHub issue.
  3. 3
    Open the issue. A maintainer turns it into a pull request - this is the human review step before any code ends up in something flashed to someone else's hardware.
  4. 4
    Once merged, CI rebuilds CydOsCommunity.bin automatically and it appears in the "Install Community Edition" section above and the gallery below - usually within a couple minutes.

Prefer to do it yourself with git? See CONTRIBUTING.md for the community-apps/<slug>/app.json format and how to open the PR directly.
