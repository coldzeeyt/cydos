Flash CydOs in one click

Puts the full multitool - WiFi radar, flashlight, clock, QR beamer, dice - on your board straight from this tab. No Arduino IDE, no esptool install, no drag-and-drop.

This browser can't do it. Web Serial only works in Chrome or Edge on a desktop computer - open this page there instead. Web Serial is blocked. This page needs to be loaded over https (it is) - check your browser hasn't disabled the Serial permission for it.

CydOs.bin · v1.2 · ~1 MB · bootloader + partitions + app, flashed at 0x0 · download the .bin to flash yourself with esptool or Arduino IDE

Before you click Install

  1. 1
    Plug in the CYD over USB to this computer - most use a Micro-USB or USB-C port on the board itself.
  2. 2
    Pick the port when the browser asks - it'll show up as something like "CP2104" or "CH340".
  3. 3
    Leave it alone while it erases and writes. Fifteen to thirty seconds, don't unplug it or touch the screen.
  4. 4
    It reboots straight into the CydOs home screen when it's done.

Board not showing up?

No serial port appears in the browser prompt

Almost always a missing USB driver for the board's serial chip - install one, then reload this page and try again:

· CP2104/CP2102 chip → Silicon Labs CP210x driver
· CH340 chip → WCH CH340 driver

Also worth checking: the USB cable is a data cable, not a charge-only one, and no other program (Arduino IDE's Serial Monitor, PlatformIO) is holding the port open.
